# eFood — Exercício M35

Projeto independente do M35, refeito a partir das telas do Figma fornecidas.

## Requisitos
- React
- Styled Components
- React Router DOM
- Home conforme Figma
- Perfil do restaurante conforme Figma
- Navegação entre as páginas
- Preparado para Vercel

## Executar
```bash
npm install
npm start
```

## Build
```bash
npm run build
```

## Vercel
- Framework: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
